# Partner- und Förderlogos (Fußleiste)

Hier gehören die Logos hin, die unten auf jeder Seite erscheinen.
Erwartete Dateinamen (siehe `footerLogos` in `src/data/site.ts`):

Zeile "Ein Festival von":
  dortmunder-u.svg
  digitale-kultur.svg
  smart-city.svg

Zeile "Partner":
  kiu.svg        (storyLab kiU)
  kolab.svg      (KoLab)
  vkii.svg       (VKII Ruhrbezirk e. V.)
  atem.svg       (ATEM Biennial)

Solange eine Datei fehlt, zeigt die Fußleiste den Namen als gestrichelten
Platzhalter an – es entsteht also kein kaputtes Bild.

Hinweise:
- SVG bevorzugt (scharf in jeder Größe). PNG geht auch, dann die Endung
  in `src/data/site.ts` anpassen.
- Die Logos stehen auf dunkelviolettem Grund. Am besten einfarbig weiß
  oder eine helle Variante verwenden.
- Dargestellt werden sie mit 2,6 rem Höhe, die Breite ergibt sich daraus.
